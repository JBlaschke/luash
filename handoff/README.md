# LuaSH 2.0 handoff

- `DESIGN.md`: what to build (architecture, interfaces, backend designs,
  compatibility, defects of the reference code, open decisions).
- `PLAN.md`: how to build it as parallel work packages, with per-package
  briefs, acceptance commands, and the parts of `AGENTS.md` that apply.
- `reference/`: the code from the design discussion, frozen, with its
  known defects in `reference/README.md`.

Read `DESIGN.md` first, then `PLAN.md` section 1, then your package brief.
